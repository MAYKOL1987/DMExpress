# Logos de marcas

Archivos descargados y usados en la franja de marcas de `index.html`. Los SVG se mantienen vectoriales; `hoka.png` es un recorte del logo visible en la fuente descargada.

## Fuentes

- `adidas.svg`: Wikimedia Commons, [Adidas.svg](https://commons.wikimedia.org/wiki/File:Adidas.svg), dominio público para el diseño gráfico del logotipo.
- `nike.svg`: swoosh obtenido del favicon oficial de [Nike Perú](https://www.nike.com.pe/), acompañado por el nombre NIKE para la franja.
- `puma.svg`: Wikimedia Commons, [Puma-logo-(text).svg](https://commons.wikimedia.org/wiki/File:Puma-logo-(text).svg), dominio público.
- `columbia.svg`: Wikimedia Commons, [Columbia Sportswear Co logo.svg](https://commons.wikimedia.org/wiki/File:Columbia_Sportswear_Co_logo.svg), dominio público para el logotipo tipográfico.
- `salomon.svg`: Wikimedia Commons, [Salomon logo 2022.svg](https://commons.wikimedia.org/wiki/File:Salomon_logo_2022.svg), dominio público para el logotipo.
- `asics.svg`: Wikimedia Commons, [Asics Logo.svg](https://commons.wikimedia.org/wiki/File:Asics_Logo.svg).
- `thenorthface.svg`: Wikimedia Commons, [TheNorthFace logo.svg](https://commons.wikimedia.org/wiki/File:TheNorthFace_logo.svg), dominio público para el logotipo.
- `hoka.png`: imagen descargada de [iconLogoVector](https://iconlogovector.com/logo/hoka), cuya página indica como fuente HOKA.com.
- `terrex.svg`: pieza tipográfica local para mostrar la denominación TERREX; no se halló un archivo de logo directo y reutilizable en la colección consultada.

Los nombres y logotipos siguen siendo marcas de sus titulares.
